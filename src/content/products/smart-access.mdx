# IOTARU Smart Access

Provides a secure, touchless access solution using encrypted Bluetooth technology. It ensures safety and convenience by allowing authorized users to open and close doors without physical keys.

## Features

- **Touchless Bluetooth Access** - Access doors safely and conveniently using BLE tags or the mobile app
- **Secure & Controlled Authorization** - Only registered and verified users can access the system
- **Temporary Access Support** - Supports temporary or time-based access for operational flexibility
- **Full Audit Trail** - Complete logging of all access events

## Specifications

| Feature | Detail |
|---------|--------|
| Connectivity | Bluetooth 5.0 LE |
| Access Method | BLE Tag / Mobile App |
| Authorization | User-based + Time-based |
| Security | Encrypted Communication |
| Audit | Full Access Logging |
