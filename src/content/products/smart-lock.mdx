# IOTARU Smart Lock

Next-generation smart lock with multiple authentication methods. Fingerprint, face recognition, and encrypted Bluetooth for maximum security and convenience.

## Features

- **Multi-Factor Authentication** - Fingerprint, face, PIN, and smartphone
- **Anti-Tamper Design** - Reinforced steel construction with alarm
- **Auto-Lock** - Configurable auto-lock timer
- **Access Logs** - Complete audit trail of all entries
- **Backup Power** - USB-C emergency power port
