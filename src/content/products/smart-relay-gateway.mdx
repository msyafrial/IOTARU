# IOTARU Smart Relay Gateway

The universal bridge for your smart home devices. Connect Zigbee, Z-Wave, Bluetooth, and Wi-Fi devices through one powerful gateway with local processing for fast, reliable automation.

## Features

- **Multi-Protocol** - Zigbee 3.0, Z-Wave, Bluetooth 5.0, and Wi-Fi
- **Local Processing** - Automations run even without internet
- **Edge Computing** - On-device AI for fast response times
- **Device Capacity** - Supports up to 200 connected devices
- **Matter Ready** - Future-proof with Matter protocol support

| Feature | Detail |
