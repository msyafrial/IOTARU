# IOTARU Smart Guard

Intelligent electronic locking system designed specifically for securing ATM machines and other critical access points. It combines encrypted Bluetooth access, real-time data reporting, and intelligent safety mechanisms.

## Features

- **Secure Bluetooth Access Control** - Access is granted through a secure Android application using encrypted Bluetooth communication
- **Universal ATM Lock System** - Designed with a universal lock tongue compatible with various ATM models
- **Real-Time Access Data Reporting** - Every access event is transmitted instantly via the user's smartphone to the server
- **Time-Based Authorization** - Support for one-time access and time-based authorization
- **Manual Key Override** - Ensures continued access in case of motor or system failure
