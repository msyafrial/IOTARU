# IOTARU LoRa Gateway Hub

Extend your IoT network to cover entire campuses, farms, or industrial facilities. This LoRaWAN gateway provides 10km+ range with support for thousands of sensors in a single deployment.

## Features

- **10km+ Range** - Long-range wireless for outdoor and industrial use
- **10,000 Devices** - Massive device capacity per gateway
- **Class A/C Support** - Optimized for both battery and mains-powered devices
- **Edge Computing** - Local data processing and filtering
- **Cloud Integration** - Direct connection to TTN, ChirpStack, and AWS IoT

## Specifications

| Feature | Detail |
|---------|--------|
| Range | 10km+ (rural) / 3km (urban) |
| Channels | 8 concurrent receive channels |
| Devices | Up to 10,000 nodes |
| Backhaul | Ethernet / 4G LTE / Wi-Fi |
| Power | PoE / DC 12V |
