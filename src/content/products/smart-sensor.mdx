# IOTARU Smart Sensor Hub

Multi-purpose sensor hub that provides comprehensive environmental monitoring. Track temperature, humidity, air quality, and motion with a single device.

## Features

- **Multi-Sensor Array** - Temperature, humidity, VOC, PM2.5, and motion detection
- **Real-Time Dashboard** - Live data visualization on web and mobile
- **Alert System** - Customizable thresholds with instant notifications
- **Data Logging** - Historical data storage with trend analysis
- **Mesh Networking** - Extends coverage through mesh network with other sensors

## Specifications

| Feature | Detail |
|---------|--------|
| Sensors | Temp, Humidity, VOC, PM2.5, Motion |
| Range | 50m indoor / 100m outdoor |
| Connectivity | Zigbee 3.0 / Wi-Fi |
| Battery | 2x AA (2 year lifespan) |
| Dimensions | 70 x 70 x 25mm |
