# IOTARU Smart Gateway

Central hub that connects and manages all your IoT devices. Enterprise-grade security, local processing, and seamless integration with the entire IOTARU ecosystem.

## Features

- **Multi-Protocol Support** - Zigbee, Z-Wave, Wi-Fi, Bluetooth, and Thread
- **Local Processing** - Edge computing for fast response times without cloud dependency
- **Enterprise Security** - AES-256 encryption with secure boot
- **Automation Engine** - Create complex rules and schedules
- **Remote Management** - Manage devices from anywhere via secure cloud
