# IOTARU Smart Hub Pro

Professional-grade IoT hub designed for enterprise deployments. Redundant connectivity, advanced security, and scalable architecture for mission-critical applications.

## Features

- **Redundant Connectivity** - Dual SIM + Ethernet with automatic failover
- **Enterprise Security** - Hardware security module with tamper detection
- **Edge Computing** - Local processing for latency-sensitive applications
- **Scalable Architecture** - Supports up to 500 connected devices
- **Remote Management** - Fleet management capabilities for large deployments
