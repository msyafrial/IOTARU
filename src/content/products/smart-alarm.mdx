# IOTARU Smart Alarm

A cutting-edge security system designed to prevent vandalism and theft of cash from ATM machines. Equipped with advanced vibration and temperature sensors, it detects unauthorized tampering or environmental anomalies in real-time.

## Features

- **Vibration & Temperature Sensors** - Monitors for unusual vibrations or rapid temperature changes that could indicate tampering
- **Real-Time 4G Data Transmission** - Every alarm event is transmitted instantly via 4G to the central server
- **WhatsApp Alerts** - Security teams and technicians receive real-time notifications through the dashboard and WhatsApp
- **Instant Detection** - Early detection before damage occurs
