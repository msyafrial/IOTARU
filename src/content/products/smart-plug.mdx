# IOTARU Smart Plug

Intelligent power outlet that adds smart control to any device. Monitor energy usage, set schedules, and control appliances remotely via the IOTARU app.

## Features

- **Energy Monitoring** - Real-time power consumption tracking
- **Remote Control** - Turn devices on/off from anywhere
- **Scheduling** - Set timers and schedules for automated control
- **Overload Protection** - Automatic shutoff for safety
- **Voice Compatible** - Works with voice assistants

## Specifications

| Feature | Detail |
|---------|--------|
| Max Load | 15A / 1800W |
| Connectivity | Wi-Fi / Zigbee |
| Energy Metering | Yes (±1% accuracy) |
| Surge Protection | 4000V |
| Certifications | UL, FCC, CE |
