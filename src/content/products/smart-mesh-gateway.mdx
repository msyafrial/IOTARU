# IOTARU Mesh Network Gateway

Build a resilient smart home network that heals itself. Mesh nodes automatically route data through the strongest path, ensuring every device stays connected even if one node fails.

## Features

- **Self-Healing Mesh** - Automatic rerouting when nodes fail
- **Multi-Hop Routing** - Data hops through multiple nodes for full coverage
- **Auto Discovery** - New devices join the network automatically
- **Distributed Intelligence** - Processing distributed across all nodes
- **Seamless Scaling** - Add nodes to extend coverage infinitely

## Specifications

| Feature | Detail |
|---------|--------|
| Mesh Protocol | Thread / Zigbee Mesh |
| Max Nodes | 250 per network |
| Hops | Up to 10 hops |
| Latency | < 50ms per hop |
| Self-Heal Time | < 1 second |
